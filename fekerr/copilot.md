# Quantum Village Simulator (qvqsim)

{ (20250421(mon) fekerr & copilot }

Quantum Village Simulator (qvqsim) is a modular, extensible quantum
simulation tool. It simulates quantum circuits by composing 2x2 unitary 
gate matrices and evaluating the final statevector. The project is split 
into several files that handle input, simulation, and output. It accepts 
circuit definitions in various formats (JSON, YAML, or a custom format).

3. Install the required packages.
4. Configure the build with Meson.
5. Run the application with Ninja.

## Getting Started

### Setting Up the Virtual Environment
Create an isolated Python environment to manage dependencies:
```bash
python3 -m venv venv
source venv/bin/activate
```

### Installing Dependencies
Install the needed packages from the provided
`requirements.txt` file:
```bash
pip install -r requirements.txt
```

### Build Setup with Meson and Ninja
This project uses Meson and Ninja for build and run control.
First, configure the build directory with Meson:
```bash
meson setup builddir
```
Then compile (or install) the files using Ninja:
```bash
ninja -C builddir
```

## How to Run
After building, run the main simulator by executing:
```bash
python qvqsim.py path/to/input_file
```
You can display help and usage instructions with:
```bash
python qvqsim.py -h
```
